## 2. What the offline scorer is
An **offline lexical proxy** (token-overlap / F1 / cosine approximations) that exercises the full scorecard pipeline — retrieval → similarity gate (≥0.82) → min-lexical cutoff (≥0.20) → fail-closed injection scan (`app/domain/sanitize.py`, L0-5.6) → 8 metrics → per-metric thresholds → pass/fail → JSON artefact. It proves the gate is wired and regression-guarded before go-live; it is **not** a substitute for LLM-judged evaluation.

## 4. What replaces it on the tenant
SAP **RagEval** produces the authoritative LLM-judged scorecard against the **live** supplier-email / schedule corpus and a curated gold set. Groundedness and context relevance need no gold set there; answer correctness / similarity / context recall are judged against the gold set. Any metric below its RagEval threshold is a release blocker (and is re-evaluated on data drift, L0-10.4).
