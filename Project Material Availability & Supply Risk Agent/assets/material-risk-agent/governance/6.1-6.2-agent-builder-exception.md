# Agent Builder / Skill Builder Exception — L0-6.1 / L0-6.2

**Agent:** material-risk-agent
**Status:** Exception REQUESTED. Agent hand-built on the pro-code LastMileSupport template because Joule Agent Builder / Skill Builder were unavailable in the build environment. Equivalence demonstrated; tenant security review requested.

Checklist items **L0-6.1 (Agent Builder in Joule Studio)** and **L0-6.2 (Skill Builder in Joule Studio)** require agents and their skills to be configured and registered via Joule Studio. Custom agents built outside Agent Builder require a documented exception plus additional security review.

## 1. Exception statement

The agent was **hand-built on the pro-code LastMileSupport Joule 2.0 A2A template** (LLM-orchestrated via `langchain create_agent` + `ChatLiteLLM` through SAP AI Core / Generative AI Hub). Joule **Agent Builder** and **Skill Builder** were **not available** in the build environment, so configuration-UI registration of the agent and its 15 skills could not be performed there.

## 2. Requested actions

1. File this exception against the AI Golden Path (1.3) deviation log.
2. Schedule the **additional security review on the tenant** that an out-of-Builder agent requires (6.1).
3. Register / re-validate the agent and its skills via Agent Builder + Skill Builder when the tenant environment is available, or formally accept the pro-code build with the review on record.

## 3. Equivalence to Agent-Builder-registered agents

| Builder-provided capability | Equivalent in this build |
|---|---|
| A2A agent card / registration | A2A card present; A2A server entry (`app/main.py`) + executor |
| Skill definitions (I/O schema, error handling) | 15 tools (12 read/compute + 3 write) with typed signatures, declared scope, errors |
| Tool access governance | RBAC + least privilege + alt-supplier HoD gating (6.5) |
| HITL approval | Confirmation gate on 3 write tools, confirmed=true (6.6) |
| Observability | OpenTelemetry step spans + structured JSON logs (6.7) |
| LLM access via Gen AI Hub | `ChatLiteLLM` routed through AI Core / Gen AI Hub (6.3) |
| Model lifecycle / version pinning | config/env-pinned model IDs, circuit breaker |

## 4. Note

Functional and governance equivalence is present; the gap is **tooling provenance** (hand-built vs Builder-registered), which the requested tenant security review closes. No capability required by 6.1/6.2 is absent — only the Studio registration step is deferred.
