# Agent Tool Dependency Map — L0-10.2

**Agent:** `material-risk-agent`
**Status:** Complete (source of truth: `asset.yaml` `requires[]` + `app/tools.py`)

Primary input to impact analysis when any dependency changes, and to the regression environment (L0-7.5) for selecting which scenarios to re-run. An out-of-date map is an Architecture Drift incident (L0-10.5).

## 4. Resolution mode (L0-10.1)
Tools are resolved **by capability** via `app/mcp_providers/agw.py::get_mcp_tools` (never hard-coded names): mock (`IBD_TESTING`) | direct-S/4 sandbox (`IBD_LIVE_S4`) | Agent Gateway (production). Tested fallback + circuit breaker when a model/tool is unavailable. Full runtime KG-based dependency resolution is **not used** (the agent grounds on OData + RAG, not SAP KG) — documented, not a gap.
