# Agent Builder Exception & Security Review — L0-6.1 / L0-6.2

**Agent:** `procurement-bottleneck-agent`
**Status:** Exception documented — **security review + tenant re-registration pending**

## 1. The exception
The agent was **built pro-code (hand-built), outside Joule Studio Agent Builder / Skill Builder**, because the SAP Joule-Studio bootstrap/skill tooling (`sap-agent-bootstrap`, `mcp-translation-file`, `setup-solution`, `mcp-mock-config`, `sap-aeval-*`) is **not available in this build environment**. The checklist explicitly permits this with a documented exception + additional security review (6.1) — this is that document.

## 2. Faithfulness to the Agent-Builder contract
The hand-built scaffold is byte-faithful to the documented Agent-Builder output:
- 3 mandatory decorators (`@agent_model`, `@agent_config` temperature-only, `@prompt_section`) — `app/agent.py`
- tool manifest with ORD IDs and action classification — `asset.yaml`, `app/tools.py`
- single versioned system prompt (`@prompt_section`) — L0-3.4
- A2A surface + agent card — `app/main.py`, `app/agent_card.py`
- LLM routed through Generative AI Hub / AI Core (L0-6.3/6.4)

## 3. Skills (6.2)
The 3 deterministic skills (`critical_path_flag`, `run_consequence_simulation`, `recommend_next_action`) are implemented in `app/skills.py` with declared input/output schema and are exposed as tools with the same manifest Skill Builder would carry. They must be **registered via Skill Builder on the tenant** at re-import.
