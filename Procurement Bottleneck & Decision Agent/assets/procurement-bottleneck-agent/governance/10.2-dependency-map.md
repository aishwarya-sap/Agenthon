## 4. Resolution mode (L0-10.1)
Tools are resolved **by capability** via `app/mcp_tools.py::get_mcp_tools` (never hard-coded names): mock | gateway | cloud/onprem. Tested fallback when a mode/tool is unavailable (`app/resilience.py`). Full runtime KG-based dependency resolution is **not used** (the agent grounds on OData/BDC/RAG, not SAP KG) — documented, not a gap.
