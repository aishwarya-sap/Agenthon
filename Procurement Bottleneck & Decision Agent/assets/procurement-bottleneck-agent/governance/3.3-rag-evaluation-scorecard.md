## 4. What replaces it on the tenant
SAP **RagEval** produces the authoritative LLM-judged scorecard against the **live** contract/history corpus and a curated gold set. Groundedness and context relevance need no gold set there; answer correctness / similarity / context recall are judged against the gold set. Any metric below its RagEval threshold is a release blocker (and re-evaluated on data drift, L0-10.4 / Loop 2).
