## 1. Model touch-points per interaction
The agent calls the LLM at two bounded points per run (intent framing + verdict synthesis). The deterministic core (simulation, decision matrix, HITL) consumes **zero tokens**. Enforced soft ceiling: **52,000 tokens/run** (`config.TOKEN_BUDGET_PER_RUN`).
