# AI Bias & Fairness Assessment — L0-5.2

**Agent:** `procurement-bottleneck-agent`
**Status:** Assessment complete for current scope — **re-evaluation cadence activates at go-live**

## 1. Bias surface analysis
The agent's decisions are driven by **numeric, document-grounded procurement signals**, not by or about people as protected classes. Decision inputs (per `app/skills.py::recommend_next_action`):
- consequence exposure (€), schedule slip (days), supplier delivery-risk score, critical-path flag, contract presence, repeat-silence count.

There are **no demographic attributes** (gender, age, ethnicity, nationality, etc.) in the feature set. "Supplier" and "vendor" are legal entities, not natural persons. The one personal field — the Project Manager's name used for notification routing (`responsible_person`) — does not enter any scoring path; it is a routing address only.

## 2. Measurement framework
- **Primary fairness concern:** consistent treatment of suppliers given equal procurement facts. Measurement = **decision parity**: identical scorecards must yield identical recommendations regardless of supplier identity.
- This is **enforced deterministically**: the decision matrix is pure Python with no supplier-identity term. The eval dataset (GOLD/EDGE records) asserts action parity on fixed inputs; `test_eval.py` fails if parity regresses.

## 3. Results
| Category evaluated | Threshold | Result |
|---|---|---|
| Decision parity on equal inputs | 100% deterministic | **Pass** (deterministic core; 111-test suite) |
| Demographic bias | N/A — no demographic features | **Not applicable, documented** |
| Supplier-identity leakage into scoring | 0 | **Pass** (no identity term in matrix) |

## 4. Customer-facing disclosure
The agent is advisory and discloses its AI nature and the financial disclaimer on every quantitative output (`config.FINANCIAL_DISCLAIMER`). Recommendations are a human decision aid, not an automated supplier judgement.

## 5. Re-evaluation cadence
No less than every six months, or after any change to the decision matrix / model. A formal fairness assessment with the RAI governance function is **pending on the tenant** (the deterministic analysis above is the engineering input to it).
